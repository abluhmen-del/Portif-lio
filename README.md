# Pet Amor

Site institucional para um pet shop com foco em acolhimento, saúde e bem-estar animal.

## Visão geral

A página foi desenvolvida com uma identidade visual moderna e acolhedora, utilizando:

- HTML semântico para estruturar as seções do site
- CSS responsivo para layout, tipografia e identidade visual
- JavaScript para interatividade e validação do formulário de contato

## Etapas de desenvolvimento

1. Identidade visual e tipografia
   - Uso da fonte Montserrat do Google Fonts
   - Definição de uma paleta de cores naturais e agradáveis
   - Estilo limpo com foco em conforto e confiança

2. Seção de destaque
   - Cabeçalho com navegação horizontal
   - Hero section com texto e botões de ação
   - Elementos sobrepostos e imagem de pet em destaque
   - Uso de posicionamento visual para reforçar a proposta da marca

3. Seção Sobre
   - Conteúdo institucional sobre a história e proposta do pet shop
   - Estrutura com Grid/Flexbox
   - Indicadores de performance e experiência

4. Seção de serviços
   - Cards com serviços principais
   - Elementos visuais e ícones para cada área de atendimento
   - Proporção de telas usando `aspect-ratio`

5. Seção de contato e interatividade
   - Formulário de contato com validação de campos obrigatórios
   - Verificação de e-mail em JavaScript
   - Mensagem de feedback para o usuário
